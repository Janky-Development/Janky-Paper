# Janky Paper - every supported Minecraft version, newest first: where its code lives on main and its mirror branch.
# Read by the "janky versions" Gradle tasks (build.gradle.kts), CI (.github/workflows/build.yml) and the release
# workflow (.github/workflows/release.yml, .github/scripts/release.py and janky_lines.py).
#
# The newest version is the repository root ("."); older ones are complete projects in versions/<minecraft version>/.
# A mirror branch is written only by the release workflow: after each release it holds exactly the code of that
# version's released jar. Edit the code on main, never on a mirror branch (the next sync would overwrite it).
#
# Minecraft 26.1 has no line of its own: 26.1, 26.1.1 and 26.1.2 share protocol 775, so 26.1 clients join
# the 26.1.x jars.
#
# <minecraft version>  <folder on main>  <mirror branch>
